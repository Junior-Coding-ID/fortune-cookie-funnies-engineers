One-line fortune cookie message for a software engineer (120 characters or fewer),
entered in the make.fun bounty
[Fortune Cookie Funnies for Engineers](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a).

## Entry

> Something you write today will outlive empires. It will be a 12-line bash script running payroll.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. The program writes the fortune to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `$MAKEFUN_OUTPUT`, default `/output/entry.txt`),
with no trailing newline.
